Movie Ticket Booking Application

Technology:
- Python
- Flask
- MySQL
- HTML
- CSS
- Bootstrap

Features:
- User Registration
- Login
- Movie Listing
- Seat Selection
- Ticket Booking
- Booking History

Database Tables:
users
movies
bookings

Booking Flow:
User logs in
Selects movie
Selects seat
Confirms booking
Booking stored in database

Project Purpose:
Allow users to book movie tickets online.
